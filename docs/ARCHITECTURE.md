# Lumi 架构

内置插件迁移的当前实现、启停边界及后续阶段见 [内置插件架构](PLUGINS.md)。可切换的产品插件为 NewAPI、Codex 用量接入、Codex 工具配置、Claude Code 工具配置、浮窗、托盘；统一系统界面保持固定，通过贡献接口接收内容、设置开关和额外侧栏页。共享 Dashboard/AppContext 保留兼容路径。

当前说明对应 0.4.31。Electron 主进程负责网络、凭据和本机文件；React 渲染器通过受限 IPC 调用业务服务。

## 分层

Codex 配置启用 `features.fast_mode = true`，并设置 `service_tier = "default"`，让 Fast 默认关闭。CLI 的 `/fast` 还要求模型能力目录声明支持 Fast。桌面版有额外的认证条件：只有 ChatGPT 官方登录（或其支持的官方个人访问令牌认证）才会显示速度选项，纯 API 密钥直连不会显示闪电图标。Lumi 保留已有官方登录，但不会创建或伪造官方登录凭据；仅改变 `requires_openai_auth` 不能代替真实登录。自定义模型名也必须被 Codex 识别为支持 Fast。Lumi 不生成模型提示词或覆盖用户模型目录。官方说明见 [Codex Speed](https://developers.openai.com/codex/speed/)。

品牌图标统一在 BrandIcon.tsx，使用本地官方 SVG。主题通过 theme.css 覆盖基础样式，最后加载 updates-trends.css 和 filters-tools-motion.css 提供更新栏、分组曲线、筛选、紧凑工具布局及切换动画，使用不透明表面与语义颜色。

浮窗采用独立 widget.html 与 sandbox preload，只接收格式化统计，不提供主应用、托盘或任意网络接口。主进程验证来源窗口、主框架和精确 URL，动作仅允许关闭、刷新、打开工作台。关闭或隐藏后停止分钟调度，退出时销毁窗口；账户切换立即清空旧统计并丢弃旧回复。上一完整分钟查询复用 New API 只读缓存，无额度消耗时最多回溯 20 页找到最近付费分钟，再读取该分钟全部明细。余额沿用站点币种设置，微小分钟消费提升精度；缺失缓存字段保留未知值，不重复加入输入 Tokens。数据动画只在统计变化时触发，状态更新和相同数据不重播。

macOS 26 起，浮窗通过 `native/macos/WidgetGlass.mm` 的 Node-API 模块使用公开 `NSGlassEffectView` 与 `cornerRadius`，按浮窗主题更新原生明暗外观。运行时检查系统版本和类可用性，旧版 macOS 或模块不可用时回退 Electron 的 HUD vibrancy；系统“减少透明度”开启时移除玻璃并使用不透明主题底色。原生视图随窗口释放，插件停用时显式移除；句柄不进入 renderer IPC。模块使用 Node-API 8，由 macOS 构建机编译及签名，发行时放在 `Resources/native/lumi-widget-glass.node`，无需用户安装开发工具。浮窗 renderer 仅接收材质名称和数值配色，保留主题文字、拖动与受限动作；Windows acrylic 和托盘材质保持各自路径。

## 配置事务

用户选择模型与渠道后，主进程验证站点和本机配置，复用 / 创建专用令牌，构造脱敏预览。应用前再次校验账户、站点、原始文件内容和预览时效，再加密备份并写入；失败尝试回滚。

每个站点 / 工具使用固定名称的专用令牌（默认 `Lumi-Codex` / `Lumi-Claude`），切换渠道更新同一 ID，不轮换密钥；旧渠道名称迁移时记录历史名称，统计同时保留旧记录归属。渠道变更发生在预览配钥阶段，令牌已有额度、有效期、模型限制与 IP 规则保留；不可用令牌不自动启用或绕过限制。应用时拒绝已被后续渠道切换修改的旧预览。

菜单栏用量参考 CodexBar，以 AppKit NSMenu 承载自定义卡片、原生分段控件和轻量图表；材质及液态玻璃外观由系统提供。`native/macos/UsageMenuBar.swift` 由 macOS 构建机编译及签名，通过标准输入 / 输出与主进程通信。主进程发送格式化统计，辅助进程只返回受限 UI 动作，不读取凭据或连接站点；退出时同时结束，故障回退为 Electron 系统文字菜单。

菜单栏使用 Lumi 自身的白色矢量标记。两个 NSSegmentedControl 均为三个等宽选项，统一 regular、automatic 和等高，由 AppKit 按系统版本与菜单环境选择原生外观，遵循 Apple [分段控件设计规范](https://developer.apple.com/design/human-interface-guidelines/segmented-controls)。选择反馈交由系统；受影响的统计区块先在禁用隐式动画的布局事务中到达最终位置，数据就绪后仅淡入，不动画化 frame 或恢复旧坐标。图表在菜单 tracking RunLoop 中插值更新；关闭菜单、连续切换和 Reduce Motion 会取消未完成动画。同账户加载快照保留上次实际呈现的模型行数，账户作用域摘要变化时立即清空。

Windows 单击托盘打开独立用量卡片，复用相同统计与缓存。窗口首次点击才创建，定位在当前显示器工作区，兼容侧边任务栏与负坐标显示器；失焦或 Escape 关闭，双击打开主窗口，右键显示系统菜单。`tray.html` 与 `tray-preload.cjs` 独立于主窗口；IPC 同时核对发送窗口、主 Frame 和准确文档地址，仅发送格式化用量并接受严格的选择 / 刷新 / 导航动作。主窗口的账户与配置 IPC 不授权此窗口。

Windows 弹窗底部贴合任务栏的工作区边缘。渲染器测量内容高度，通过受限 layout IPC 报告 160–648 px 范围；主进程从当前 bounds 逐帧插值并保持底边位置。可见状态使用独立序号，重复数据快照不重放入场动画；首次并发打开共享加载任务，退出动画完成后隐藏窗口，过期完成事件不能关闭已重开的面板。减少动态效果时立即调整高度与关闭。

Windows 内容区保留滚动，但不显示滚动条；高度插值期间内容宽度保持一致，避免右侧滚动条闪现。标题、选择器和底部操作固定在可视区域。

菜单栏与托盘按需读取汇总并隔离账户，汇总缓存跟随独立刷新间隔，默认一分钟。只有弹出面板可见时定时刷新；隐藏详细区块时跳过完整消费分页，显示效率、Token 明细或工具曲线时按需读取，最多 10,000 条且明细缓存五分钟。设置中的菜单栏与托盘分栏控制余额、本期用量、Token 明细、效率、曲线及模型；AppKit 与 Windows 卡片按可见区块收紧高度。时间和工具选择按站点持久保存，账户、站点、选择或日期变更会拒绝旧的在途响应。

本期用量与消费趋势各有独立时间偏好：跟随面板、今日零点起、最近 24 小时、7 天、30 天。工具选择同时应用于两个范围，明细 / 效率 / 主要模型跟随本期用量；相同范围复用查询，趋势隐藏时跳过独立趋势请求。24h 使用完整日志，避免整小时聚合包含范围外记录。独立趋势失败保留已取得的本期汇总，范围名通过原生状态分别发送。

Codex 修改真实模型 ID、provider、地址、认证与上下文设置，尊重活动 profile 和 CODEX_HOME。不会定义或复制提示词，也不生成模型目录。旧版 Lumi 模型目录引用可迁移，原目录内容保持不变。

同步涉及本程序管理的相关会话最新设置与可用索引字段，保留历史回合和用户指令。应用与恢复不检查或阻止运行中的 ChatGPT / Codex；完成后提示用户需要重启 Codex / CLI，使新配置生效。应用、备份与恢复覆盖相关文件和索引行，并保留文件身份、哈希与索引冲突检查及失败回滚。

Codex 预览只读取小型配置 / 认证文件和 SQLite 配置冲突快照，完成专用配钥后立即返回脱敏预览；不会扫描请求历史。显式应用时读取相关会话，逐块处理 JSONL，仅解析元数据和最近的 thread_settings_applied 记录，其他渠道及大请求正文快速跳过。使用字节偏移保存少量记录差异，复制时以 SHA-256 和文件身份检查每个未修改字节，再通过同目录临时文件原子替换；保持 CRLF、UTF-8 和历史正文原始字节。Windows 短暂读句柄占用导致替换失败时，最多追加 40 / 80 / 160 ms 等待，每次重试复检原文件身份；持久占用或外部修改停止替换。配置 / 认证文件限制 8 MB、待解析单条会话配置记录限制 2 MB；超限给出可读错误并停止写入。

新版备份清单只包含小配置和索引，相关会话差异分别加密写入 .part 文件；不把全部请求历史与两份全文合并成大字符串。备份列表只读取清单，恢复按完整文件 hash 校验再反向应用差异；旧版 v1 备份继续兼容。写入、会话和索引失败尝试完整回滚，阶段进度通过只向主窗口发送的受限 IPC 呈现。前端防止重复操作和旧站点响应写回，应用成功立即更新本机配置状态，在后台同步偏好，不等待账户全量统计刷新。

Claude Code 合并 CLI settings.json 中的 API 配置，保留无关设置；Claude Desktop 不属于当前集成范围。所有模型的选择依据本站可达渠道，不按目录缺少协议标签禁用。

## 网络与数据

公开状态不携带凭据，账户请求使用作用域快照。切换站点、退出或改变身份会使旧请求和配置预览失效。并发续期 / 配钥分别共享任务，拒绝跳转和 TLS 校验绕过。

主进程的只读缓存由作用域客户端共享，按站点、地址、账户凭据摘要及查询参数隔离。余额 / 令牌缓存 30 秒，日志 15 秒，用量 / 健康度 1 分钟，状态 / 定价 5 分钟；最多 256 项，失败不缓存。手动刷新及站点写操作失效相关缓存，在途旧任务不能写回。缓存不写入账户或浏览器存储，命中后仍校验作用域。

按令牌曲线及效率统计复用完整消费分页，返回纯用量点和汇总指标，超过 10,000 条要求缩小时间范围。效率统计在后台读取并缓存 5 分钟；图表沿用动态粒度，超过 8 个分组将其余合并，保留总量并允许任意单项查看。

HTML 内联启动页在主脚本加载前可显示，React 在本机设置初始化时沿用同一界面。`bootstrap` 只返回本机设置与运行环境，工具配置由 `inspectConfigs` 后台读取；首页动态资源提前加载，账户数据与公开状态并行请求。详细效率统计后加载，初始化失败提供重试，无人为等待时间或伪进度。

Windows 使用当前用户 NSIS 安装包，程序文件只在安装和更新时解压。Electron 在读取设置前创建最终主窗口并载入本地矢量加载画面，随后在同一窗口载入主页面，避免位图缩放和两次窗口交接。electron-updater 延迟初始化，版本检测只在工具页运行。

统计筛选按站点保存范围、模型数组和令牌 ID 数组。起止时间为本地分钟，结束分钟包含 59 秒，今天上限截断到当前时刻。分钟范围或多选条件需要完整日志，缓存按账户和时间范围共享，不因筛选组合重复分页；10,000 条上限、缺失令牌 ID 或分页变化时停止准确统计。24h 使用随时钟滚动的过去 24 小时范围，按完整日志统计并以 24 个小时桶绘图；1 天从本地零点到当前时刻，7 / 30 天使用日历范围。保存的是 24h 选择而非固定日期。普通日期范围继续使用站点小时统计。切换范围保留旧仪表盘，成功后替换；账户变化才清空。工作台、模型广场等所有页面统一遵循设置中的自动刷新间隔，窗口不可见时暂停；关闭自动刷新仍允许手动刷新。

工作台除账户余额外，消费、Tokens、请求数、效率、趋势、模型分布和最近活动全部来自同一筛选区间；区间汇总不可用时保留未知值，不拿账户累计数替代。首页不再额外查询今日消费或今日调用，工具配置集中在独立页面，工作台不再显示“你的开发伙伴”摘要块。

模型广场按实测卡片高度填入最短列，保留收藏置顶、名称排序和 DOM / 键盘顺序；ResizeObserver 在宽度、档位或内容变化后重新放置。目录监控复用成功的页面同步结果，独立于当前页面，不额外轮询站点。首次建立静默基线；后续比较模型增删、公布倍率、公式 / 插件 / 用量字段定义、渠道与额度换算规则，不比较运行时求值结果、健康度或描述。分时倍率随时钟变化不提示，分时公式自身修改会提示。按站点 ID / URL 摘要隔离；目录请求失败保留旧基线，存储失败则退回本次会话。

目录基线除字段指纹外，仅白名单保存限长公共计价数值、经受限 AST 重建的公式、渠道倍率和用量字段，不保存账户、凭据、模型描述或插件展示名称。新旧规则在同一检测时刻通过现有定价解析器对比，并保存有界的历史档位展示快照；即使只改了 Fast 或长上下文，默认档位未变的价格仍可显示。监控复用模型广场的卡片外框，默认选择默认计价来源、默认上下文和普通请求模式；切换档位后展示输入 / 输出 / 缓存单价、计费单位及时间规则，变更项目高亮并显示旧值 → 新值。模型基础价与渠道倍率分别说明，新增与下架使用检测时的公共价格，站点规则单独成卡。界面不展示公式，非线性或无法安全解析的规则明确显示单价未知。旧指纹及仅保存变更明细的历史兼容读取，不使用当前目录补写历史价格。最多保留 20 次事件、每项 96 条明细，档位快照严格限制条目、文本及总预算；总存储 8 MB，损坏数据校验失败后静默重建基线。

CLI 检测优先继承 PATH 的实际入口，再补充用户 / 系统 PATH 和常用位置，排除 Windows App Execution Aliases。状态缓存 30 秒，工具页与窗口重新获得焦点时检测。安装 IPC 仅接受 codex / claude 枚举，使用固定官方安装器；npm 更新锚定原前缀。安装输出限长并脱敏，下载失败不执行，结束后重新读取实际版本。测试使用注入执行器，不安装用户本机工具。

ChatGPT 桌面版本通过系统安装元数据读取，Windows 兼容已知 OpenAI.Codex / CodexBeta 注册名并核对 ChatGPT.exe，优先正式版。CLI 最新版来自官方 npm 包，Windows ChatGPT 最新版来自 Microsoft Store 正式目录并匹配当前架构；成功缓存 30 分钟、失败缓存 5 分钟，手动重新检测跳过缓存。先发送本机状态，再补充最新版，远程失败不改变安装状态。macOS ChatGPT 最新版暂不可查。

macOS 工具页后台读取登录 Shell 的 PATH，保留原路径优先并补充 Homebrew 与常见版本管理器，Node 所在目录加入执行环境；npm / CLI / 安装器复用同一环境。Shell 检测限时 5 秒，并发任务共享，手动检测会刷新；启动首页不等待 Shell。

macOS 使用隐藏标题栏和原生交通灯按钮，侧栏顶部保留按钮空间，主页面不重复显示 Windows 控件。菜单保留编辑、窗口、显示和退出操作，关闭主窗口时隐藏并通过 Dock 激活重新显示。侧栏导航独立滚动，底部设置 / 更新 / 站点固定。

Windows 侧栏跨越顶栏行并从窗口顶部开始，标题栏保留右侧原生窗口操作与拖动区；完整顶部预留只用于 macOS。统计筛选和本地目录监控由页面统一提供 14 px 间距，取消各提示栏额外底部 margin。MotionSwap 过滤子动画完成事件，并在动画取消或关闭时释放保留高度。

运行日志从主进程加载时写入内存，记录启动、主进程控制台、界面控制台、IPC 操作耗时、请求状态、工具检测和更新阶段。日志不记录请求体、响应体或认证头，并在写入时脱敏常见密码 / 密钥 / Cookie 字段及 URL 查询；最多 10,000 条，每条 4,000 字符。只读快照与实时订阅均通过受限 preload 提供，界面每 150 ms 合并显示，每页最多 300 条；暂停仅冻结显示，重新进入可读取本次启动的全部保留记录，不写文件。

默认占位站点没有网络请求。初次配置后的数据来自用户选择的服务器；登录、余额、消费、模型与健康度不使用演示数据。缺失元数据保留“—”或灰色采样条。

远程登录窗口无 Node / preload / Lumi IPC，站点权限请求与任意新窗口被拒绝。凭据和原始配置备份由系统加密存储保护，密码不落盘。浏览器预览只提供公开状态，不处理账户凭据。

GitHub 更新服务独立于账户 API，正式安装包使用 electron-updater 的 GitHub / NSIS Provider。启动后及每 4 小时检查，校验正式版本与固定文件名；下载和重启前验证大小及 SHA-512。发布包含 latest.yml 和 blockmap。点击重启更新后调用 quitAndInstall(true, true)，后台安装并重开；autoInstallOnAppQuit=false，正常退出不自动升级。

更新提示和设置页使用同一状态订阅；隐藏版本号作为全局偏好保存，设置页始终保留查看和恢复入口。GitHub 构建在 Windows x64 与 macOS ARM64 本机分别打包；Mac DMG 使用临时签名并核验应用及 Electron 架构，Electron / Chromium 许可另复制入应用 Resources，发布时合并两平台校验清单。

检测到未隐藏或跳过的新版本后，先显示更新说明窗口，下载仅在“立即更新”之后开始。Windows 读取 electron-updater 提供的 Release 说明，macOS 读取 GitHub Release body；统一去除 HTML、脚本及控制字符，最多展示 32,000 字符，React 按文本渲染。“跳过该版本”与隐藏提示是两个独立的全局设置，跨重启保存；下一版本重新提示，设置中可手动查看和安装已跳过版本。下载成功后继续执行 Windows 重启安装或 macOS 打开安装窗口。

macOS ARM64 更新读取固定 GitHub 仓库的最新正式 Release，仅接受对应 DMG 名称、大小与 GitHub 的 SHA-256 digest。下载到本机更新目录并清理取消的临时文件，校验后才提供打开入口，打开前再次核验。成功打开 DMG 的 Finder 安装窗口后自动退出 Lumi，用户将新应用拖入 Applications 替换；文件被修改或 Finder 打开失败时保留应用，并提供重试。此流程不自动覆盖 Applications 中的文件。

下载进度的 received / total 直接表示更新引擎报告的网络传输字节，完整安装包大小单独使用 packageSize。增量下载、转为完整下载以及未知传输总量均分别呈现；校验安装包不伪造网络下载完成量。侧栏和更新说明窗口使用同一个格式化函数，按二进制 B / KB / MB / GB 显示合理精度。

应用从安装位置启动后在后台清理已安装及更旧的所有历史安装包，覆盖 userData/updates、electron-updater 当前缓存与旧产品名回退目录中的已知 Lumi 文件，不依赖单次下载记录。新版本安装包、待安装文件及关联元数据保留；下载、校验或安装期间保护更新缓存。macOS 从挂载 DMG 内运行时保留安装包，替换应用并从安装位置成功启动后清理。启动检查等待首次清理完成；失败的清理限次重试，不阻塞启动画面。

设置中的应用缓存按需计算网页 HTTP / 代码 / GPU 缓存与已知更新安装包占用，提供重新计算和清理，不全局轮询。清理仅针对固定缓存根下的普通文件，跳过链接、越界路径和未知更新文件；浏览器原生清缓存也受路径检查约束。缓存服务串行执行，与更新服务互斥启动新下载 / 安装；账户设置、Cookie、Local Storage、IndexedDB、模型变动记录和工具备份保留。开发及测试使用独立 userData / sessionData 和更新目录。

请求明细显示日志显式报告的思考强度（reasoning_effort / reasoning.effort），缺失值为 —；不从模型名或配置推断。最近活动栏目以当前站点的 overview.activityColumns 独立保存，保留模型图标和可点击错误详情；CSV 完整字段同样带有思考强度。

请求明细的 duration 列显示首字 / 后续耗时，与单独的 firstToken 列同时选中时隐藏重复项。netSpeed 为可选列，不改写已有列选择；净速率只使用有效流式首字时间和正后续耗时。完整日志产生 netOutputTokens、subsequentDurationSeconds 与 netSpeedSamples，趋势摘要、时间桶及分组的其它曲线按同一有效样本合计后计算净速率，缺失数据保持 null；不直接平均每条记录的速率。CSV 保留原字段次序并追加后续耗时及净速率。

趋势的 speed 使用与模型效率统计相同的有效输出 Tokens / 总耗时口径，包含首字等待。outputTokens、durationSeconds、speedSamples 在摘要、时间桶和分组合并时累加，再计算加权速率；无有效样本保留 null。speed 与 netSpeed 是独立的站点选择，切换指标复用完整日志。

## 紧凑浮窗与数据刷新

浮窗保持 244×64 的单一内容树：消费为所选范围全部消费合计，模型信息取范围内时间最新的实际请求（同秒按记录 ID），不按费用大小挑选模型。模型 Tokens 用无标签的“输入 / 输出”展示，缓存读取数字置于输入下方（10 px 淡色，主数值 14 px）；缓存写入、时间、历史回溯说明与详细状态进入悬停提示。账户切换立即替换旧快照，关闭停止请求，元数据更新不重播动画。

widgetDataSource 保存 API / 本地会话选择。API 模式按分钟缓存，本地模式限制每秒最多读取一次；每个 JSONL 文件保存内存字节偏移及未结束行，以 64 KiB 只读流块继续读取追加内容，处理截断、替换与跨块字符。不限制总文件大小，不把完整文件载入字符串；保存最近 30 天分钟聚合，widgetPeriod 从单次调用到 30 天，切换范围不重读；刷新串行处理，定价实际变化才重新报价。读取不写文件、不加独占锁，也不上传会话内容。widgetInputMode 默认 total（未命中输入 + 缓存读取），uncached 扣除缓存读取，两种数据源一致，缓存写入独立且不改变费用。

工作台与站点消费趋势使用完整请求日志的精确时间，将实际开始到结束范围等分为最多 30 段；整数秒边界相邻且不重叠，全部日志只计入一个桶。缓存命中率为桶内有效成功请求缓存读取 / 对应输入，未知值为 null，合并其它曲线时先合并原始计数再计算比例。汇总与图表使用相同范围，指标 / 分组切换复用数据，不额外拉取日志；菜单栏原有小时采样保持原粒度；本机会话也按扫描开始时的固定范围分 30 段，按日汇总表保留。

全局偏好 dataRefreshAnimation 保存六种效果，IPC 枚举校验，旧偏好及无效值默认向上。主程序统计、效率、最近活动、请求明细与趋势使用 DataRefreshMotion，浮窗使用窄桥接相同 keyframes。每次实际数据变化先退出 120 ms，提交最新快照后进入 220 ms（模糊 300 ms）；没有叠加旧新两棵 DOM 树。连续更新取消先前动画和迟到完成事件，卸载取消监听；账户隔离、关闭动画及系统减少动态效果立即显示最新数据。设置提供即时预览。


本地浮窗共享线上账户与定价缓存（账户 30 秒、模型定价 5 分钟），不请求 API 消费日志。实际报价使用站点公布的默认模型规则与已配置渠道，p/c/cr/cc/cc1h 按独立的真实 Tokens、len 按调用上下文，时间条件按调用时间评估。仅模型规则显式区分缓存 TTL 时才分拆写入；未知变量、缺失 TTL、不可用渠道或自定义请求字段返回 null，显示未知消费。余额始终来自线上。

本机会话汇总以 64 KiB 只读流块遍历固定文件大小，报告真实字节 / 文件进度。标题读取 Codex session_index.jsonl、Claude sessions-index.json 和日志名称事件，缺少名称时使用首条真实用户问题，跳过环境及系统注入。详情只接受已扫描会话的 SHA-256 ID，不允许渲染器传入路径。

local-session-store 完整扫描一次建立临时 SQLite 索引，数据库仅保存调用计数、事件字节位置和每个 64 KiB 块的摘要，正文留在原始文件。SQLite 页缓存限制 2 MiB；每个服务最多 2 个加载任务、4 个活动快照，15 分钟失效。只读文件句柄、文件身份、大小、时间和块摘要检查保护快照，真实追加不纳入已打开快照。调用每页最多 50 条、内容每页 20 条，原始记录每块最多 64 KiB，并保持 UTF-8 字符边界。单条超过 8 MiB 时不解析为大字符串，保留完整字节索引并允许分块查看；无效或未写完的记录明确提示。

Codex 用累计差值恢复调用用量，按 turn_id / turn_context 关联同轮内容，不能精确区分请求时明确标注。Claude 用消息标识在磁盘索引中替换流式用量，并关联用户上下文和工具结果。会话内容归一化为纯文字预览，单条最多 32 KiB，附加字段有界，附件仅描述、不自动访问。界面只保留当前页和原始内容块，隔离旧会话 / 筛选 / 账户的迟到响应；取消或关闭会话释放句柄与临时索引。内容不上传，不记录到应用日志。旧的元数据游标接口保留兼容测试，不参与新版详情加载。


## 来源贡献与 Codex 订阅限额

工作台及用量插件现在是展示壳。New API 通过卡片及用量标签贡献显示账户/账单，本地来源提供独立会话标签，`provider.codex` 提供 ChatGPT 订阅卡片。卡片与标签明确 `site`/`independent` 作用域；切换 New API 站点不重挂载 Codex 或本地来源。来源筛选在 `sourceSelections` 保存，独立于站点的 `viewSelections`，旧本地筛选按当前站点一次性迁移。

Codex 接入通过主进程能力 `subscriptionUsage.read` 和固定 IPC `readCodexUsage` 调用本机 CLI app-server。CLI 管理自己的账户认证，读取账户和限额、复核账户后关闭隐藏子进程。限额窗口长度、重置时间和积分均以服务返回为准；缺值保留未知，订阅配额与站点账单/本地 Tokens 不混算。读取有时间/输出上限、作用域缓存和停用回收；不发送模型请求、认证变更或积分兑换命令。测试使用 mock CLI 和隔离目录，详情见 [PLUGINS.md](PLUGINS.md)。

## 统一系统与产品插件贡献

工作台、用量分析、模型广场、令牌管理和工具配置是固定的统一系统模块。NewAPI、Codex、浮窗、托盘及 Codex / Claude Code 工具适配器各可独立启停。NewAPI 声明工作台/用量分析/模型广场/API令牌四个显示子项，Codex 声明工作台子项；子开关只撤回贡献，父开关停止整个提供者或桌面表面。工具适配器在设置的“工具配置”分组管理，系统工具页使用可选依赖，撤回一个适配器不影响另一个工具的表单和草稿。停用撤销所属预览、阻止安装及配置提交/恢复，保留配置文件与加密备份；进行中的配钥或写入阻止停用。NewAPI 停用关闭网络/缓存、隔离迟到数据并清除配置预览；已启用工具的本地检查、安装及恢复仍可使用。

插件在 manifest.settings 声明设置组/开关，group: tools 指定工具配置分组；renderer 可贡献系统卡片/标签/内容、自己的设置组件和带命名空间的侧栏页面。设置以“内置插件 / 工具配置 / 额外插件”分组展示，父组可折叠，末级插件行及开关右侧的设置按钮打开同一详情弹窗。弹窗包含介绍、状态、自身设置和显示子项，首次打开才挂载活动设置组件；关闭保留已访问组件草稿和列表分组/滚动，恢复触发按钮焦点，失活立即撤回组件。settings.sections 声明插件自己的具名设置项，兼容 settings.component；外部设置继续通过隔离 frame。贡献可关联声明过的 view，默认值、保存和校验由宿主管理。Codex/Claude 适配器提供工具专属字段，系统协调事务；停用提供者不能中断正在执行的配钥或配置提交。

主窗口的对话框和筛选浮层复用 `PopupLayer`，统一 portal 到当前界面外壳、父级可见性、层级、Escape/外部关闭及焦点管理；`Modal` 负责标题与内容外框，`PopupPresence` 管理关闭后卸载及退出兜底，受控 `open` 可保留草稿。退出立即停止交互，页面/账户范围变化立即撤回旧内容；插件生命周期变化仍可撤回退出内容，不因普通开关操作重置整张详情。原生下拉保持平台键盘语义，使用可离散过渡的 display/overlay 保留关闭动画；减少动态效果时立即结束。多选搜索栏高度固定，列表单独收缩和滚动。

常规设置的“连接”选项和设置页顶栏通过 renderer 的 `connections` / `settingsTabs` 注册，宿主只保留常规设置和实时日志。停用插件撤回对应选项、标签及内容；当前标签被撤回时回到常规设置，设置页本身保持挂载。Windows 与 macOS 使用贯穿顶部的拖动标题栏，圆角侧栏位于标题栏下方，保留左右及底部的外壳间距。

工具版本检测由主进程按活动适配器筛选，ChatGPT 桌面版本仅随 Codex 工具检测；两工具都停用时不发起检测。重新启用触发检查，renderer 以请求序号、工具集合和页面生命周期拒绝旧结果。已经开始的只读检查可完成，禁用工具的事件不更新工具页。模型卡片快捷入口跟随活动工具，搜索等快捷配置也验证适配器状态及代次再跳转。

浮窗、托盘分别消费无界面 usage.present/workbench.present 能力，独立管理窗口、刷新任务和清理。提供者/表面激活代次进入缓存身份；重新启用重新获取能力，不复用已撤销的服务。插件内容容器保留纵向间距；设置页切换滑块保持挂载及编辑状态。详情见 [PLUGINS.md](PLUGINS.md)。

两个表面的 runtime 位于各自插件内，拥有受限面板 IPC、缓存、计时器、主题订阅和平台图标/helper。主进程只提供平台环境及操作接口，插件宿主经通用 `surface.control` 发出更新通知。停用完整释放资源，重新启用创建新 runtime；不从主窗口的挂载状态读取数据。

## 独立界面插件

`plugins/interface.default/` 提供默认外壳的 JSX 和桌面布局，`App.tsx` 通过受限 `InterfaceShellProps` 传入状态与动作，并保留所有账户/请求/偏好管理。标题栏、悬浮侧栏、滚动容器、搜索和通知随界面插件维护；系统功能页面仍通过稳定 children 插槽挂载。

外部 `kind: interface` 包以清单/CSS/LICENSE 独立分发，不编译进 EXE。renderer 宿主将 CSSOM 校验后的规则包装到插件专属 `@scope`，一次只能选中一个包。该接口 v1 提供布局/皮肤，不运行外部脚本或替换宿主 React 树。设置切换只更新样式，保留草稿、焦点和滚动；选中包丢失/变更或样式无效时采用默认布局。设置中的“默认界面”可撤回额外样式，样式错误也在该设置区域显示；功能插件及其数据生命周期不受界面切换影响。契约和作者示例见 [额外插件指南](../extensions/README.md#界面插件-v1)。

## 独立分发的额外插件

`extensions/packages/` 与 `plugins/` 分开：前者是 JSON 清单和自包含 web 文件包，不参与 Vite/esbuild，不进入安装 EXE/app.asar，打包后单独输出到 release 的 extensions 目录。应用扫描用户数据的 extensions 目录；开发时还扫描仓库包，安装后也支持 resources/extensions 旁置包。作者可直接提交独立包，无需修改内置注册表或重新构建宿主。

清单贡献由 renderer adapter 映射到系统卡片/来源、连接、设置顶栏和侧栏。每个外部界面运行在没有同源权限的 sandbox frame，经专用 lumi-extension 协议读取本次扫描的固定资源。宿主 SDK 通过 nonce/source 校验的消息中转和固定 main handler 调用受控接口，包无法访问主窗口 DOM、preload、Node/文件系统或任意 IPC。网络权限只允许声明来源的公共 HTTPS GET，不跟随重定向，DNS 固定、TLS 校验、超时及大小有界；独立密钥保持系统加密，只允许用于受控请求，不提供明文读取。

外部启用状态、子开关和数据与内置配置分开保存。新包/变更摘要默认停用；启停、重新扫描和账户上下文变化使旧响应失效。关闭包立即撤回全部贡献，重新扫描不重挂载设置页。接口 v1 和作者流程见 [extensions/README.md](../extensions/README.md)。


## 界面与桌面表面的主题同步

主窗口、widget、tray 复用 `src/theme-tokens.css` 的浅/深色语义变量。主窗口弹出层挂载到稳定 `.desktop-shell` 以继承外部界面插件的局部样式；曲线、图例和下拉控件使用语义颜色。Windows 顶栏提供 Lumi 标识，主页面不再展示底部站点/同步状态栏。

界面宿主在样式与主题更新后通过 Chromium 解析共享颜色，以固定 `syncSurfaceTheme` IPC 发送有界数值 RGBA；主进程校验发送窗口/框架/地址、完整字段、当前界面 ID 和已解析的主题。颜色只存内存，界面切换或样式变更撤销旧配色，更新浮窗/托盘已有窗口，不重新扫描用量或重启刷新任务。独立 preload 仍只有原来的窄操作；不传 CSS、资源 URL 或账户权限。macOS helper 接收同样的数值颜色和浅/深色状态，保留 AppKit 原生材质。
