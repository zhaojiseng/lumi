# 内置本地录制网关传输层

这些模块由 Lumi 项目独立编写，使用主仓库 MIT 许可证；初始实现同步自独立插件仓库 `sources/gateway-runtime/dev/`。主程序把模块打入 Electron 主进程，只使用随应用构建的固定 Rust 核心可执行文件，不接受插件传入的文件路径、命令或管理令牌。

`management.mjs` 的 `prepareConfiguration` 是主程序内部的配置事务屏障，不在 HTTPS 管理协议或插件 SDK 中开放。它检查当前配置版本与退出状态，再由运行时冻结和提交热配置；已接收请求继续使用旧快照。Rust 核心负责系统加密存储和原子事务；Node 传输层负责 loopback HTTP/TLS、公共上游检查和流式转发。

`catalog.mjs` 提供已保存供应商目录与受限草稿目录读取；草稿认证仅用于本次查询，不持久化。固定 GET 路径、协议认证、公共 DNS 审查与 TLS 校验，不执行模型推理，也不写入 AI 请求录制库。目录查询有独立并发、分页、响应和总时限，不占用管理串行队列；连接撤销、运行资源关闭或配置变更时拒绝旧结果。构造器网络注入仅供隔离测试，SDK 不开放 URL、请求头或网络选项。

`transport.mjs` 的数据监听另提供固定 `GET /<routeID>/v1/models`，完整保存配置仅一条路由时兼容裸 `GET /v1/models`。目录沿用路由客户端鉴权并复用 catalog，最多返回 500 项/128 KiB 的 OpenAI 模型列表及截断标记；不调用核心推理/录制方法。目录占共享请求限额，正常排空可完成、取消会中断网络、配置变更拒绝迟到结果。管理与数据目录共用同一 catalog 实例及私密字段反射防护。
